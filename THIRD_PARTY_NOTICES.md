# Third-party assets and dependencies

Cassette Studio's original source code is licensed under MIT. This license does not grant rights to games, music, trademarks, or assets supplied by users.

- Probably Stolen game assemblies and vanilla sprites are referenced from the user's own installation. They are not included in this repository or in generated mod packages. The tool is an unofficial community project.
- FFmpeg / FFplay / FFprobe, .NET, Python, and SteamCMD are external dependencies and are not bundled. Their own licenses and terms apply.
- User music files, personal pack configurations, Steam credentials, Workshop upload sessions, generated mod binaries and archives are excluded from this repository.
- `assets/default-gift-box.png` is an AI-generated crystal-themed placeholder created for this project. It is not an official game asset or logo.
- The demo audio is generated by `tools/create_demo_pack.py` from simple original sine-wave melodies; no commercial game soundtrack is included.

Game API references and guides: https://github.com/dragonpan2/probably-stolen-modding
